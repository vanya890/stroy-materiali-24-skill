# Stroy-Materiali-24 — skill для ИИ-агентов

Скилл (Agent Skill), который превращает ИИ-агента в консультанта по каталогу
интернет-магазина стройматериалов
[Stroy-Materiali-24.ru](https://stroy-materiali-24.ru/): Москва, Московская
область, доставка в Калужскую область.

Внутри — снимок полного YML-фида магазина: **1554 товара в 98 категориях**,
цены, фасовки, вес, описания, ссылки на карточки, карта каталога, готовые
комплекты и расчёты, условия доставки и оплаты.

## Зачем это нужно

Агент без данных о магазине придумывает позиции, цены и «наличие». Этот скилл
даёт ему проверяемую базу и правила ответа:

- находит товар по названию, бренду, размеру, категории и цене;
- называет цену, фасовку и ссылку на карточку — и помечает дату снимка;
- считает количество на площадь по расходу из описаний производителя;
- собирает комплекты под задачу: штукатурка, стяжка, наливной пол, плитка,
  ГКЛ-перегородка, утепление фасада, покраска, кладка, каркас, гидроизоляция;
- честно говорит «в каталоге нет», если товара нет (плитка, сантехника,
  ламинат, обои, газобетон и т. п.);
- объясняет доставку, самовывоз, оплату и возврат, явно показывая
  противоречия в данных магазина.

## Быстрый старт

### Claude Code

```bash
git clone https://github.com/vanya890/stroy-materiali-24-skill.git \
  ~/.claude/skills/stroy-materiali-24
```

Скилл подхватится автоматически: Claude Code читает `SKILL.md` из
`~/.claude/skills/<name>/`. Для отдельного проекта клонируйте в
`.claude/skills/stroy-materiali-24` внутри репозитория.

### OpenCode

```bash
git clone https://github.com/vanya890/stroy-materiali-24-skill.git \
  ~/.config/opencode/skills/stroy-materiali-24
```

Или положите папку в `.opencode/skills/` проекта. OpenCode также читает
`AGENTS.md`, который ссылается на этот скилл.

### Другие агенты (Cursor, Codex, Gemini CLI, ChatGPT)

- **Cursor / Codex / Gemini CLI** — склонируйте репозиторий в проект; агент
  увидит `AGENTS.md` и `SKILL.md` и будет следовать правилам.
- **ChatGPT (Projects / Custom GPT)** — загрузите `SKILL.md`,
  `references/*.md` и `data/products.jsonl` в файлы проекта и попросите
  агента следовать инструкциям из `SKILL.md`.
- **Любой агент с доступом к shell** — дайте ему этот репозиторий и попросите
  использовать `python scripts/search.py` для поиска по каталогу.

Скилл следует формату [Agent Skills](https://agentskills.io/): `SKILL.md`
с YAML-frontmatter (`name`, `description`), плюс справочники и данные.

## Что внутри

| Путь | Назначение |
|---|---|
| `SKILL.md` | Инструкции агенту: как искать, считать, отвечать, чего не выдумывать |
| `references/catalog.md` | Карта категорий: что где лежит, сколько позиций, диапазон цен |
| `references/store.md` | Контакты, адрес, часы, доставка и тарифы, оплата, возврат, FAQ |
| `references/buying-guides.md` | 13 готовых комплектов и расчётов под типовые задачи |
| `data/products.jsonl` | 1554 товара: название, цена, категория, описание, вес, ссылка, фото |
| `data/categories.json` | Дерево категорий со счётчиками и ценами |
| `data/meta.json` | Метаданные снимка: дата фида, источник, счётчики |
| `scripts/search.py` | Поиск по снимку без интернета (Python 3.8+, только stdlib) |
| `scripts/sync.py` | Обновление снимка из YML-фида |

## Поиск из командной строки

```bash
python scripts/search.py штукатурка гипсовая --limit 5
python scripts/search.py "фанера ФСФ 18"
python scripts/search.py --category "Плиточный клей" --max-price 500
python scripts/search.py "утеплитель" --category "Утеплитель" --sort price
python scripts/search.py --id 308723241
python scripts/search.py --categories "смеси"
python scripts/search.py "клей" --json -n 3
python scripts/search.py --stats
```

Поддерживаются сокращения: `гкл`, `осб`/`osb`, `эппс`/`xps`, `шпатлевка`,
`свп`. Все параметры — в `python scripts/search.py --help`.

## Обновление данных

```bash
python scripts/sync.py            # скачать свежий фид и пересобрать всё
python scripts/sync.py --check    # только проверить доступность фида
python scripts/sync.py --file feed.xml
```

Скрипт перезаписывает `data/*` и `references/catalog.md`. В GitHub Actions
настроен еженедельный автосинк (`.github/workflows/sync.yml`): если фид
изменился, бот коммитит обновление.

## Важно о точности

- Цены — **снимок фида от 23.10.2026**, за единицу товара, без доставки.
  Актуальную цену и остаток подтверждает магазин.
- В фиде `available: true` у всех позиций и нет остатков: «есть в каталоге»
  не равно «есть на складе».
- Флаги `pickup`/`store` в фиде всегда `false`, хотя самовывоз работает —
  это особенность выгрузки.
- Расхождения магазина (тарифы доставки на странице и в позициях каталога,
  часы работы, стоимость разгрузки) описаны в `references/store.md` и не
  сглаживаются.
- Скилл — справочник, а не официальный канал продавца: он не оформляет
  заказы, не резервирует товар и не гарантирует цены.
